# CodingStandards

Práctica de laboratorio de Ingeniería de Software II: Estándares de codificación con Checkstyle.

## Informe

El informe completo de la práctica (capturas del proceso, configuración y los dos
reportes Checkstyle) está en este repositorio:

**[Informe_CodingStandards_AlejandroTapia.pdf](Informe_CodingStandards_AlejandroTapia.pdf)**

Si la plataforma de entrega no permitió adjuntar el PDF por su tamaño, esta es
la evidencia de que el archivo sí está disponible aquí, en la raíz del repositorio.

## Contenido del repositorio

- `src/main/java/labcodingstandards/Calculator.java`: código corregido según las reglas de Checkstyle.
- `checkstyle.xml`: configuración de reglas usada.
- `suppressions.xml`: exclusiones de verificación.
- `pom.xml`: configuración de Maven y del plugin de Checkstyle.
- `reportes/reporte1-antes/`: reporte generado antes de corregir el código (36 errores).
- `reportes/reporte2-despues/`: reporte generado después de corregir el código (0 errores).
